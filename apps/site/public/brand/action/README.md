# Action logo assets

Generated by `bun run brand` from `src/components/ActionMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `action-light.svg`, `action-dark.svg` | The mark for light and dark backgrounds |
| `action-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `action-icon.svg`, `action-icon-{size}.png` | The app icon on Apple's grid |
| `action-favicon.svg` | Browser tab icon: the tile edge to edge |
| `action-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

Generated from the approved ActionMark component with the compact square viewBox (15 35 590 590). Geometry and aspect ratio are preserved.

The site hero uses the precomputed SVG. The full construction drawing remains a configurable React component.

`products/action/native/engine/CoreSources/ActionBrandMark.swift` ports the same geometry for the menu bar and the in-app chip.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product. The glyph's longer side spans 66% of the tile, lifted 1.2% of the tile to balance its weight. The favicon drops the margin and grows the glyph 18%.

Measured glyph bounds in viewBox units: 69.736, 99.819, 498.965 × 472.173.

On macOS the export also writes `products/action/assets/brand/Action.icns`, which the app build copies into the bundle.

It also keeps `products/action/assets/brand/action-icon-512.png` and `products/action/assets/brand/action-icon-1024.png` in step with the icon.
