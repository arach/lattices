What changed its mind: the ops console asked “what is the agent doing” and the fleet feed asked “what happened anywhere.” Both answers were already conversational — a question from the agent, a command from you, an outcome. What moved where

Agent console → chatDecisions become agent messages with inline reply chips (approve/steer/dismiss). Steps and stats were idle filler; the question was always the content.FleetAgentConsole, FleetFocusPane retire
Fleet feed → chatAction outcomes land as quiet system lines in the conversation. Watcher churn (WIN/PROC/OCR/TMUX) never enters; it stays on the Mac’s own activity page.FleetFeedPanel retires; CompanionActivityLog filtered at the adapter
Command bay → tile gridThe oversized cards compress to a 6×2 grid of compact shortcut buttons. Sets still switch from the strip’s overflow.FleetCommandBay slimmed
Trackpad → heroThe strip becomes the left two-thirds, with the frontmost-window preview riding on top — the physical center the deck advertises.FleetTrackpadStrip promoted
Layouts toggleops/focus/split retire with the console; one anatomy, no modes to learn.FleetDeckLayout enum dies
New: typed inputThe keyboardForwarding capability ships at last: a text field beside push-to-talk.net-new bridge path
Key row + lockable modifiersOne row in five clusters: modifiers (tap to arm, amber), edit keys, space, arrow cluster, enter. ⌘ armed + L sends ⌘L; chording is how a touch remote stays a keyboard.extends existing key row
Tiles → two rowsTwelve shortcut buttons in a 6×2 grid: window moves, app/window switching, mouse tools, preview, clipboard.command bay → tile grid
Trackpad: drag windowThird mode beside pointer/scroll. Touch grabs the frontmost window and moves it live across the Mac’s displays. Direct manipulation, not a tile command.net-new deck action, AX move by delta
Chat agent → ScoutThe rail’s agent turns route through the Scout broker already on the Mac. Questions and needs-you bubbles are flights; inline replies resolve them. No new orchestration layer.bridge → scout ask
