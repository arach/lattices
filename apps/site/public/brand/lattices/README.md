# Lattices logo assets

Generated by `bun run brand` from `src/components/LatticesMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `lattices-light.svg`, `lattices-dark.svg` | The mark for light and dark backgrounds |
| `lattices-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `lattices-icon.svg`, `lattices-icon-{size}.png` | The app icon on Apple's grid |
| `lattices-favicon.svg` | Browser tab icon: the tile edge to edge |
| `lattices-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

A 3 × 3 grid with the left column and bottom row lit: the L. The site header draws the same component with `theme` unset, so it follows the `--logo-ink` and `--logo-dim` tokens and their hover states.

`public/favicon.svg` is a copy of `lattices-favicon.svg`.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product. The glyph's longer side spans 56% of the tile, as in every product icon. The favicon drops the margin and grows the glyph 18%.

Measured glyph bounds in viewBox units: 1.992, 1.992, 16.016 × 16.016.

On macOS the export also writes `assets/AppIcon.icns`, which the app build copies into the bundle.
