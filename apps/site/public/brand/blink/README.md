# Blink logo assets

Generated by `bun run brand` from `src/components/blink/BlinkMark.tsx`. Edit the component, not these files.

| File | Use |
| --- | --- |
| `blink-light.svg`, `blink-dark.svg` | The mark for light and dark backgrounds |
| `blink-{light,dark}-{size}.png` | The same, transparent, at 16, 24, 32, 48, 64, 80, 128, 256, 512, 1024 px |
| `blink-icon.svg`, `blink-icon-{size}.png` | The app icon on Apple's grid |
| `blink-favicon.svg` | Browser tab icon: the tile edge to edge |
| `blink-touch-icon.png` | 180 px home screen icon, square and opaque |

Theme names describe the intended background, so `light` is dark ink. The PNGs are proportional exports, not separately optically adjusted drawings.

A panel frame with two blocks stepping across it. The page header draws the same component in `currentColor`.

The kit follows the landing page: bottle green on parchment, near-white on black. The app icon keeps the desk’s amber on near-black.

## App icon

An 824 px tile in a 1024 canvas with continuous corners, shared by every Lattices product. The glyph's longer side spans 56% of the tile. The favicon drops the margin and grows the glyph 18%.

Measured glyph bounds in viewBox units: 1.995, 1.995, 14.01 × 14.01.

On macOS the export also writes `products/blink/assets/AppIcon.icns`, which the app build copies into the bundle.

It also keeps `products/blink/assets/AppIcon.svg` in step with the icon.
