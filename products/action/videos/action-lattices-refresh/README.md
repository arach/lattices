# Action / Lattices film

21-second 1920×1080 HyperFrames composition. Narration: ElevenLabs Sarah, generated via SpeakEasy; closing line regenerated separately with ElevenLabs to remove an unwanted trailing utterance. Closing alignment and transcription are included.

Render with HyperFrames 0.8.31:

```sh
bunx hyperframes@0.8.31 render . --quality high --output ../../docs/assets/action-record-the-work.mp4
```

The website consumes the rendered MP4, poster, and WebVTT captions in `products/action/docs/assets/`. Source captures and approved brand artwork are frozen in `capture/assets/`.
